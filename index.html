What is this?

This tool explores faction identity in BattleTech through mech usage data. It answers questions like "What mechs define the Draconis Combine?" or "Who should I paint this Griffin for?"

How it works

Data comes from two sources: MegaMek's force generator (community-curated mech availability tables) and the official Master Unit List (canon confirmation).

  • Each faction has a weight (1–10) for each chassis — how likely they are to field it. Higher = more common. Each +2 on this scale doubles the probability.
  • Signature measures how much a mech belongs to a faction. It combines usage (do they field it a lot?) with distinctiveness (does anyone else?). A mech only one faction uses scores very high. A mech everyone uses scores low.
  • Distinctiveness ratings (T1–T5) group mechs by natural breaks in the data. T1 = the faction's totemic mechs.

Key assumptions

  • MegaMek data is the primary source. It's community-curated and richer than the official MUL, but may include reasonable extrapolations beyond strict canon.
  • Mode B (default) filters by canon. If the MUL says a faction doesn't have a chassis in that era, it's excluded. Mode A shows everything MegaMek has.
  • Weight class distribution matters. Factions that invest heavily in heavies get more sig credit for their heavy mechs. A Lyran Atlas counts more than a Lyran Locust in the identity ranking.
  • Unit quality is averaged by default. Some mechs are elite-only or garrison-only. The default view averages across all tiers. Use rating=A or rating=F to focus on a specific tier.
  • Signature is global and stable. Adding or removing factions from your query doesn't change any faction's distinctiveness scores.

Distinctiveness ratings

  • DR1 — Faction-defining. The totemic mechs. Start here if painting for one faction.
  • DR2 — Strong identity markers. Clearly associated.
  • DR3 — Moderate association. Above-average usage.
  • DR4 — Weak association. Present but not distinctive.
  • DR5 — Incidental. The faction has access but it's not "theirs."

Tiers use Jenks Natural Breaks — a statistical method that finds natural gaps rather than arbitrary cutoffs.

How signature is computed

z = (weight - mean) / stddev    (across ALL factions, non-fielding = 0)
signature = weight × max(0, z)

The z-score measures how unusual this faction's usage is. Non-fielding factions count as 0, so a mech only one faction fields produces a very high z-score. Weight class distribution is applied before the z-score in mixed-class views.

Combined Score (Cmb)

The combined score answers: "How strongly does this faction both prefer and field this chassis?" It normalizes DR and Prob to 0–1 each, then sums them:

DR_norm  = DR / 4.0          (clamped 0–1)
Prob_norm = log₂(prob) / 5.0  (clamped 0–1)
Combined  = DR_norm + Prob_norm  (range 0–2)
  • High Cmb — Distinctive AND common. The faction's signature mechs.
  • High DR, low Prob — Distinctive but rare. Specialist equipment.
  • Low DR, high Prob — Common but generic. Workhorse mechs everyone uses.
  • Low Cmb — Neither distinctive nor common for this faction.

The normalization bounds (4.0 for DR, 5.0 for Prob) are derived from the data model’s theoretical maximums, so the score is stable across queries and eras.

Split cell display

The default faction column shows DR | Prob | Cmb as a split cell. Click the column header to cycle through sort modes — the active metric gets a ▼ arrow. Each click advances: DR → Prob → Cmb → DR. You can also view DR, Prob, and Cmb as separate columns via the ☰ Columns menu.

Heat map

Faction weight cells are colored cool-to-warm based on raw weight. Weight 1 = coolest, weight 10 = hottest. Independent of signature — a cell can be warm (high usage) but low signature (everyone else uses it too).

Mode B (MegaMek × MUL)
DR = faction distinctiveness · Prob = battlefield likelihood · Cmb = combined signature

DR (Distinctiveness Rating) — How strongly a mech is associated with a faction. DR1 = iconic, DR5 = incidental. A mech only one faction fields scores high; a mech everyone uses scores low.

Prob (Probability Weight) — How likely this mech is to actually show up in a faction's forces, accounting for both availability and the faction's weight class preferences. Higher = more battlefield presence.

Cmb (Combined Score) — How strongly a faction both prefers and fields this chassis. Combines normalized DR and Prob into a single 0–2 score. Higher = more iconic to the faction. A high-Cmb mech is both distinctive and common in their forces — a true faction signature. Click the column header to cycle through DR, Prob, and Cmb sorting.
